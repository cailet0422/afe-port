## 특징

- SDL2로 Windows(32·64비트), Linux, Android(ARM 32·64비트)에서 에뮬레이터 없이 직접 실행되고, OpenGL 3.3 /
  OpenGL ES 3.0, Vulkan, (Windows에서는) Direct3D 12로 그립니다([그래픽 API](#그래픽-api)).
- 디스크 이미지에서 바로 읽으며, 원래 이미지는 바꾸지 않습니다.
- 포트 전용 일시정지·설정 메뉴: 게임 위에 뜨는 창으로, PC는 마우스·키보드(또는 게임패드), Android는 손가락으로
  조작합니다. 한국어/영어. 화면 설정, 음량, 키보드·게임패드 키 바꾸기, 디스크 폴더, 한글패치, HD 텍스처, 멀티플레이.
- **HD 텍스처**: 메뉴에서 Dolphin용 HD 텍스처팩 zip을 설치합니다
  ([Animal Crossing HD Texture Pack](https://forums.dolphin-emu.org/Thread-animal-crossing-hd-texture-pack-version-25-october-11th-2026)
  v25 기준. TechieAndroid와 기여자들의 작업으로, 이 저장소의 것이 아니며 따로 받아야 합니다). zip을 풀지 않고
  바로 읽고, 플레이하면서 불러오며, 한글패치가 바꾼 텍스처는 건드리지 않습니다([HD 텍스처](#hd-텍스처)).
- **서버 없는 멀티플레이**: 내 마을에 방을 열면(공개방, 또는 방 코드·비밀번호가 있는 비공개방) 같은 네트워크나
  인터넷의 친구가 기차를 타고 놀러 옵니다. 서로 보고(각자의 마이디자인 옷 그대로), 채팅하고, 같은 마을에서 아이템을
  떨어뜨리고 줍고 심고 팝니다. 주민, 가구, 날씨, 상점, 박물관도 호스트를 따릅니다. 호스트는 손님을 내보낼 수
  있습니다([멀티플레이](#멀티플레이)).
- **자동 저장**: 야외에서 1분마다, 건물에 들어가고 나올 때, 게임을 끌 때 스스로 저장합니다. 그냥 꺼지거나 튕겨도
  많아야 1분 남짓만 잃습니다. 새 마을도 하니와가 저장해 줄 수 있게 되는 때부터 저장됩니다. 첫날은
  처음 만난 주민과 대화를 마치면 곧바로 저장됩니다. 그래서 도루묵씨(리셋씨)는 기본으로 나오지 않습니다([저장](#저장)).
- 한글패치 지원: 게임 안에서 패치 zip을 골라 바로 적용하고, 한국어와 일본어를 언제든 오갈 수 있습니다.
  실제 키보드(두벌식)나 화면 키보드로 한글을 입력합니다.
- Android: 화면 터치 게임패드(버튼 위치와 크기를 바꿀 수 있음), 손가락으로 세상을 직접 누르며 하는 **풀 터치 모드**(누른
  곳으로 걷기, 주민과 물건 누르기, 소지품·지도 아이콘, 도구 칸, 집 안 가구 배치 모드; [터치 조작](#터치-조작)), 실제
  게임패드, 비정상 종료 시 다음 실행 때 크래시 리포트 표시.
- 미니맵: 마을 야외에서는 왼쪽 아래에 마을 지도가 작게 나옵니다(내 위치와 보는 방향, 주민 집).
  **M** 키로 언제든 게임의 전체 지도를 열고 닫을 수 있고(파출소에서 지도를 받기 전에도), Android에서는
  미니맵을 터치하면 열립니다. **Settings** → **Gameplay** → **Minimap**에서 끌 수 있습니다.
- 구역 이어 걷기: 마을 야외에서 한 구역에서 다음 구역으로 경계에서 멈추지 않고 그대로 걸어가고, 카메라가 따라
  넘어옵니다. 둘레 구역도 이미 살아 있어서 집, 돌아다니는 주민, 곤충, 물고기 등이 도착하기 전부터 그 자리에 있습니다.
  **Settings** → **Gameplay** → **Seamless acres**(구역 이어 걷기)에서 끄면 게임큐브처럼 넘어갑니다.
- 자동 업데이트: v1.0.0부터 게임을 켤 때 새 릴리즈가 있는지 확인하고 설치를 제안합니다(세이브, 설정,
  디스크, 한글패치는 그대로). **Settings** → **Gameplay** → **Updates**에서 끌 수 있습니다.
- 패미컴 가구 게임(최고 점수 저장 포함)과 부팅 징글도 동작합니다.
- 게임큐브 메모리 카드 세이브(GCI)를 `afe_gci` 도구로 가져오고 내보낼 수 있습니다(소스에서 빌드).

## 시작하기

### Windows / Linux

1. 받은 zip을 풀고, 풀린 `DobutsuNoMoriEPlus` 폴더 안에 `rom` 폴더를 만들어 디스크 이미지를 넣습니다.
   Windows에서는 이 단계를 건너뛰어도 됩니다. 이미지를 찾지 못하면 이미지가 있는 폴더를 고르는
   안내(**폴더 선택**)가 뜹니다.
2. `DobutsuNoMoriEPlus.exe`(Linux는 `./DobutsuNoMoriEPlus`)를 실행합니다. 세이브는 같은 폴더의 `save/`에
   생깁니다.

### Android

1. 디스크 이미지를 폰의 폴더에 둡니다(예: `Download/동물의숲`. `Download` 바로 아래는 고를 수 없으니
   그 안에 폴더를 만듭니다).
2. APK를 설치하고(출처를 알 수 없는 앱 허용) 실행한 뒤, **폴더 선택**으로 그 폴더를 고릅니다.
3. 화면 터치 게임패드, 풀 터치 모드([터치 조작](#터치-조작)), 실제 게임패드로 플레이합니다. 터치 게임패드의 START
   왼쪽 **SAVE**(풀 터치 모드에서는 상자에 화살표가 들어가는 아이콘)를 누르면 바로 저장합니다.

APK는 정식 키로 서명되어 있어(인증서 SHA-256
`db6fc1ad60b6b6d980bee0990f120ef481f195f117729fa194b124d14752e8b7`) 새 버전을 덮어서 설치해도 세이브가
유지됩니다. 세이브는 `Android/data/org.afedecomp.dobutsunomori/files/save/`에 있습니다.
앱이 비정상으로 끝나면 다음 실행 때 게임을 띄우기 전에 원인을 보여 주는 창이 뜹니다. **복사**를 눌러
이슈에 붙여 주세요.

### 업데이트

v1.0.0부터는 위의 다운로드가 스스로 업데이트됩니다. 게임을 켤 때
[릴리즈](https://github.com/cailet0422/afe-port/releases)를 확인해서 새 버전이 있으면 일시정지 메뉴가 열리고
**Update now**(지금 업데이트), **Later**(나중에), **Skip this version**(이 버전 건너뛰기) 중에서 고릅니다.

- Windows / Linux: 새 zip을 받아 릴리즈의 `SHA256SUMS.txt`와 맞춰 본 뒤 게임 폴더의 파일을 바꾸고,
  **Restart now**를 고르면 새 버전으로 다시 시작합니다. `rom/`, `save/`, `korean/`과 설정은 건드리지
  않습니다. 게임 폴더에 쓸 수 있어야 합니다(`Program Files` 안은 안 됨). Linux에서는 `curl`이나 `wget`이
  필요합니다.
- Android: 새 APK를 받아 확인한 뒤 시스템 설치 화면을 엽니다(Android가 물으면 이 앱의 설치를 허용하세요).
  기존 버전 위에 설치되어 세이브와 한글패치가 그대로 남습니다.

업데이트는 이 저장소의 릴리즈에서만 받고, 소스에서 빌드한 게임은 스스로 업데이트하지 않습니다.
**Settings** → **Gameplay** → **Updates**에서 확인을 끌 수 있습니다(`settings.ini`의 `auto_update = 0`).
v0.1.6 이하는 스스로 업데이트하지 못하니 v1.0.0은 한 번 직접 받아 주세요.

### 그래픽 API

**Settings**(설정) → **Video**(화면) → **Graphics API**(그래픽 API)에서 게임이 무엇으로 그릴지 고릅니다. 다음 시작부터
적용됩니다.

- **OpenGL**(기본): Windows와 Linux는 OpenGL 3.3, Android는 OpenGL ES 3.0.
- **Vulkan**: Vulkan 드라이버가 있는 Windows, Linux, Android 7.0 이상.
- **Direct3D 12**: Windows 10 이상.

셋 다 같은 그림을 그립니다. Vulkan과 Direct3D 12는 CPU에 시간을 더 남기므로(그리는 것마다 드라이버가 하는 일이 적고,
셰이더는 다른 스레드에서 준비합니다) 휴대폰과 느린 PC에서 가장 도움이 됩니다. GPU가 어느 쪽에서 더 빠른지는
드라이버에 따라 다르니 직접 바꿔 보세요. GPU에 맞춰 만든 셰이더는 `shader_cache/`에 남습니다. 어떤 API로 처음
시작하면 플레이하는 동안 뒤에서 준비하고, 다음부터는 그대로 씁니다.

고른 API를 기기에서 시작할 수 없으면 OpenGL을 쓰고 메뉴에 그렇게 표시합니다. Vulkan이나 Direct3D 12로 시작하다가
게임이 죽으면(드라이버 문제) 다음에는 OpenGL로 시작하고 메뉴에도 그렇게 바꿔 둡니다. `settings.ini`의 `renderer`도 같은
설정이고(0 OpenGL, 1 Vulkan, 2 Direct3D 12), `--renderer vulkan`(또는 `opengl`, `d3d12`)은 한 번만 그 API로 실행합니다.

### 저장

게임이 묻지 않고 하니와의 "저장하고 계속하기"처럼 마을을 저장합니다.

- 내 마을 야외에 있고 특별한 일을 하고 있지 않을 때(메뉴·대화 중이 아니고, 아이템을 들어 올리고 있지 않을 때)
  1분마다. 그런 순간이 올 때까지 기다립니다.
- 건물에 들어가거나 나올 때(20초에 한 번까지).
- 메뉴에서 게임을 끄거나 창을 닫을 때.

새 마을도 같은 방법으로 저장합니다. 첫 저장 때 하니와에서 처음 저장할 때처럼 메모리 카드에 마을 파일을 만듭니다.
첫날은 하니와도 주민을 한 명이라도 만난 뒤부터 저장해 주므로, 처음 만난 주민과 대화를 마치면 몇 초 안에 그 자리에서
(야외든 건물 안이든) 바로 첫 저장을 하고 알림을 띄웁니다. 이미 마을 파일이 있는 마을에 새로 이사 온 주민도 첫날
같은 방법으로 저장됩니다.

바로 저장하려면 **Ctrl+S**(PC)나 터치 게임패드의 START 왼쪽 **SAVE**를 누르세요. 집 안 방에서도, 자동 저장을 꺼
두었어도 됩니다. 저장했다는 알림이 뜨고, 아직 저장할 수 없을 때는 이유를 알려 줍니다(대화·메뉴 중, 동작 중, 섬,
첫날 주민을 만나기 전).

하니와에서 저장하는 것도 그대로 됩니다. 마을이 늘 저장되므로 저장하지 않고 꺼서 처음부터 다시 할 수는 없습니다.
새로 시작하려면 **설정** → **게임** → **마을 데이터** → **마을 데이터 초기화...**를 쓰세요. 메모리 카드마다 있는
마을(과 플레이어)을 보여 주고, 한 번 더 확인한 뒤 고른 마을을 지우고 게임을 다시 시작합니다. 그러면 새 게임으로
시작합니다. 지운 마을은 되돌릴 수 없습니다. 저장하지 않고 꺼도 플레이가 남으니 **도루묵씨(리셋씨)는 기본으로 오지
않습니다**. **Settings** → **Gameplay** → **자동 저장**에서 자동 저장을 끄고, **도루묵씨(리셋씨) 등장**에서 다시
나오게 할 수 있습니다(`settings.ini`의 `autosave = 0`, `autosave_every = 1`(분, 1–60), `resetti = 1`). 멀티플레이로
다른 마을에 놀러 가 있는 동안에는, 집에 기차로 돌아갈 때처럼 내 마을 파일에 그때의 주머니·벨·편지가 저장됩니다.

### 한국어로 플레이하기

한글패치는 이 프로젝트와 별개인 팬 패치입니다.

1. [retrodb 한글패치 — 동물의 숲 e+](https://retrodb.info/krpatch/7428/%EB%8F%99%EB%AC%BC%EC%9D%98-%EC%88%B2-e)에서
   패치 zip을 받습니다(패치 v0.9.2·v0.9.3 확인).
2. 원래 디스크로 게임을 실행하고 일시정지 메뉴(PC는 **Esc**, Android는 **뒤로** 버튼) → **설정** →
   **디스크·한글** → 한글패치 **설치...**를 누릅니다.
3. 받은 zip을 그대로 고릅니다(Windows·Android는 파일 선택 창, Linux는 먼저 게임 폴더의 `patch/`에 zip을
   넣어 둡니다).
4. 1초 안팎으로 끝나면 **지금 다시 시작**을 고릅니다.

한글판 이미지는 `korean/`에 따로 만들어지고 원래 이미지는 그대로 남습니다. 같은 탭의
**한국어로 플레이** 스위치로 한국어판과 원래 디스크를 오갈 수 있습니다.

> 텍스처팩의 이용 조건은 원본 배포처를 따르고, 텍스처팩 자체에 관한 문의·요청은 원본 스레드로 해 주세요.

- 원본 출처: [Dolphin 포럼 — Animal Crossing HD Texture Pack](https://forums.dolphin-emu.org/Thread-animal-crossing-hd-texture-pack-version-25-october-11th-2026)

**설치**

1. 위 링크에서 zip을 받습니다. 풀지 않아도 됩니다.
2. 일시정지 메뉴 → **설정** → **HD 텍스처** → **텍스처팩 설치 (zip 선택)...**에서 받은 zip을 그대로 고릅니다.
   zip은 게임 폴더의 `texture_pack/`(Android는 앱 폴더)으로 복사되고 바로 켜집니다. 파일 선택 창이 없는
   Linux에서는 zip을 `texture_pack/`에 직접 넣고 **다시 읽기**를 누릅니다.
3. 다시 시작할 필요 없이 플레이하면서 바뀝니다.

**알아 둘 것**

- 한글패치와 함께 써도 패치가 바꾼 텍스처(로고, 이름표, 한글 글꼴과 글자)는 바뀌지 않습니다. 한국어로 실행할
  때는 팩에 든 다른 언어 글자 텍스처(`Localisation/`)도 쓰지 않습니다.
- 이 팩은 북미판 Animal Crossing용입니다. e+와 똑같은 텍스처만 바뀌고, e+에만 있거나 글자가 다른 텍스처는
  원래대로 나옵니다.
- 텍스처는 처음 그릴 때 불러오므로, 처음 가는 곳에서는 잠깐 원래 텍스처가 보였다가 바뀔 수 있습니다.
- 메모리를 많이 씁니다. 휴대폰은 대부분 팩의 압축 형식(BC7)을 직접 쓰지 못해 풀어서 쓰기 때문에, Android는
  **크기**가 기본으로 **절반**입니다. 느려지거나 앱이 꺼지면 **크기: 절반**으로 두거나 텍스처팩을 끄세요(크기와
  불러오기 방식은 다시 시작하면 적용됩니다).
- **HD 텍스처 사용** 스위치로 바로 끄고 켤 수 있고, 설치한 팩은 같은 화면의 **삭제**로 지웁니다. zip 크기(160MB)만큼
  저장 공간이 필요합니다.
- 자세한 내용: [docs/texture_pack.ko.md](docs/texture_pack.ko.md)

### 멀티플레이

서버 없이 친구의 게임과 직접 연결해서 한 마을에서 최대 8명이 함께 놉니다. 한 사람(호스트)이 자기 마을에 방을
열고, 다른 사람(손님)은 자기 마을 기차역에서 기차를 타고 호스트 마을로 놀러 갑니다. 동작 원리는
[docs/multiplayer.ko.md](docs/multiplayer.ko.md)에 있습니다.

**방 열기 (호스트)**

1. 방을 열기 전에 마을에서 한 번 저장합니다. 손님에게 보낼 마을 파일이 있어야 합니다.
2. 일시정지 메뉴 → **멀티플레이**에서 방 이름, 공개방 여부, 비밀번호(선택), 최대 인원(2–8명)을 정하고
   **방 열기**를 누릅니다.
3. 공개방은 같은 네트워크와 인터넷의 방 목록에 나옵니다. 비공개방은 화면에 나온 **방 코드**(복사 버튼)를 친구에게
   알려 주세요. 비공개방은 코드로만 들어올 수 있습니다.
4. 참가자 목록의 **내보내기**로 손님을 내보낼 수 있습니다. 내보낸 사람은 그 방에 다시 들어올 수 없습니다.
   **방 닫기**를 누르면 모두 방에서 나가게 됩니다.

**참여하기 (손님)**

1. 일시정지 메뉴 → **멀티플레이**에서 방 목록의 방을 골라 **참여**하거나, **방 코드**에 받은 코드(또는
   `IP:47070` 같은 주소)를 넣고 **참여**합니다. 비밀번호가 있으면 넣습니다.
2. "호스트 마을을 받는 중..."이 끝날 때까지 기다립니다.
3. **내 마을 기차역**에서 역무원에게 말을 걸어 여행을 부탁합니다. 게임이 내 마을을 저장한 뒤 기차로 호스트
   마을에 도착합니다.
4. 돌아올 때는 호스트 마을 역에서 평소처럼 기차를 탑니다. 거기서 얻은 물건은 가지고 돌아옵니다.

같은 마을에서는 서로 이름표와 함께 보이고, 채팅은 머리 위에 몇 초 동안 뜹니다. 바깥의 아이템은 모두에게 똑같이
바뀝니다: 버리기, 줍기, 놓기, 구멍 파기·메우기, 묻기, 심기, 열매 흔들기, 나무 베기, 잡초 뽑기. 다른 사람에게
보일 이름은 **내 이름**에서 정합니다(비우면 내 캐릭터 이름).

**채팅**: 방에 있는 동안 PC는 **T** 키, Android는 화면 위쪽의 **말풍선 버튼**을 누르면 채팅창이 열립니다. 입력하고
**Enter**(Android는 **보내기**)로 보내고, **Esc**(Android는 **닫기**나 창 밖을 누르기)로 닫습니다. 채팅창이 열린
동안 게임은 멈추지 않지만 내 캐릭터는 움직이지 않습니다. 새 채팅은 화면 위쪽에 몇 초 동안 나오고, Android에서는
읽지 않은 채팅이 있으면 버튼에 빨간 점이 뜹니다. 키는 설정 → 조작 → **채팅 (멀티플레이)**에서 바꿀 수 있습니다
(게임패드 버튼도 됩니다). PC에서 한글은 컴퓨터의 한글 입력기(한/영)로 칩니다.

**유의사항**

- **모두 같은 버전**의 게임을 써 주세요. 버전이 다르면 들어가지 못할 수 있습니다.
- 손님도 **자기 마을이 저장**되어 있어야 하고, 호스트와 **다른 이름의 마을**이어야 합니다. 그리고 손님 캐릭터가
  **너굴 상점 아르바이트를 끝낸 상태**여야 합니다. 그 전에는 역무원이 당분간 기차가 오지 않는다고 합니다(원래 게임의
  규칙).
- 함께 쓰는 것은 호스트의 마을뿐입니다.
- **주민은 호스트 쪽을 따라 움직입니다.** 호스트 근처에서 돌아다니는 주민은 손님 화면에서도 같은 자리로 걷거나
  뛰어가고, 호스트가 없는 곳의 주민도 같은 구역에 있습니다. 다만 주민과의 대화·인사는 각자의 것이라, 대화하는
  동안 그 주민은 내 화면에서 멈춰 있다가 끝나면 다시 따라갑니다. 집에 들어가고 나오고 자는 때도 호스트와 같습니다.
  **주민 집 안**에서도 호스트가 같은 집에 있으면 주민이 호스트 쪽과 같은 자리로 방 안을 걸어 다니고, 호스트 쪽
  주민이 방에 들어오면 함께 들어옵니다. 섬 주민, 곤충·물고기는 각자의 게임에서 따로 움직입니다.
- **호스트 집의 가구는 실시간으로 반영됩니다.** 호스트가 가구를 놓거나 옮기거나 돌리거나 치우면, 또 벽지·바닥을
  바꾸면 손님 게임에도 바로 바뀝니다. 손님이 그 방 안에 있으면 손님이 메뉴·대화 중이 아니고 가만히 서 있거나 걸을
  때 가구가 다시 놓입니다. 전등·TV·라디오 켜짐/꺼짐, 오디오에 넣은 음악, 서랍 같은 가구 안의 물건, 하니와 스텝도
  호스트를 따릅니다. 남의 집 가구는 원래 게임처럼 옮길 수 없습니다.
- **마이디자인이 그린 그대로 보입니다.** 마이디자인 옷은 모두에게 그 사람이 그린 디자인으로 보이고(디자인을
  고쳐도 바로 바뀝니다), 호스트 집의 마이디자인 벽지·바닥·현관문도 손님에게 그대로 보입니다.
- **손에 든 도구가 보입니다.** 잠자리채, 도끼, 낚싯대, 삽, 우산(마이디자인 우산은 그린 그대로), 풍선, 바람개비,
  부채, 꽃, 크래커를 든 모습이 다른 사람에게도 보이고, 팔도 그것을 든 자세가 되며 잠자리채를 휘두르거나 낚싯대를
  던지는 움직임도 같습니다. 줍거나 파낸 물건을 들어 보이는 모습도 보입니다.
- **그 밖에 호스트를 따라 함께 바뀌는 것**: 서로의 동작(줍기, 나무 흔들기, 낚시... 같은 애니메이션), 날씨, 마을
  멜로디, 박물관, 게시판, 파출소 분실물, 너굴 상점, 에이블 시스터즈 진열, 우체국, 무 시세, 방문객 이벤트, 눈사람.
  손님이 그 장소에서 바꾼 것(게시판 글, 분실물 가져가기, 사고팔기, 마을 멜로디)은 호스트에게 가서 모두에게 퍼집니다.
  집 바깥 모습(크기, 지붕 색, 지하실, 우편함 깃발), 집 앞 하니와(손님이 사면 물건은 손님 주머니로 가고, 판 값은
  호스트 쪽 하니와에도 집주인 몫으로 쌓임), 주민들의 데이터(옷과 우산, 이사 오고 가기), 추가 다리, 등대, 낚시 대회,
  블랑카, 마을 평가와 그 밖의 마을 이벤트도 따릅니다.
- 놀러 가 있는 동안에도 손님의 마을 파일에 손님의 주머니와 벨이 저장됩니다([저장](#저장) 참고).
- 두 사람이 같은 아이템을 같은 순간에 주우면 먼저 주운 사람이 갖고, 다른 사람의 주머니에서는 다시 빠집니다.
- 호스트 마을에 있는 동안 손님 게임의 시계는 호스트의 시계를 따릅니다.
- 호스트가 방을 닫거나 게임을 끄면 방이 끝납니다. 이미 호스트 마을에 있던 손님은 그 마을에 그대로 있다가
  기차로 집에 돌아가면 됩니다.
- 아직 실험적인 기능입니다. 중요한 세이브는 미리 백업해 두세요(게임 폴더의 `save/` 복사).
- **개인정보**: 방 코드에는 호스트의 인터넷 IP 주소가 들어 있고, 공개방은 그 주소가 BitTorrent DHT에 공개됩니다.
  아는 사람끼리만 놀려면 비공개방과 비밀번호를 쓰고, 코드는 믿을 수 있는 사람에게만 알려 주세요.

**다른 네트워크(인터넷)로 할 때**

- 같은 와이파이·공유기에 있으면 바로 됩니다.
- 다른 네트워크라면 호스트 공유기에 UPnP가 켜져 있는 것이 가장 좋습니다. 게임이 공유기에 UDP 47070 포트를 직접
  열어 달라고 하고, 멀티플레이 화면에 "(공유기 포트 열림)"이 뜹니다. UPnP가 없으면 공유기 설정에서 UDP 47070을
  호스트 기기로 포트포워딩하세요. 포트가 안 열려도 서로 길을 뚫는 방식(홀펀칭)으로 연결을 시도합니다.
- 화면에 "(공유기가 다른 공유기 뒤에 있어 연 포트가 쓰이지 않음)"이 뜨면 공유기 앞에 공유기가 하나 더(통신사
  모뎀 겸 공유기 등) 있는 것입니다. 바깥쪽 공유기에서 포트포워딩하거나 브리지 모드로 바꾸세요.
- 인터넷으로 들어갈 때는 서로를 찾느라 30초쯤 걸릴 수 있습니다.
- 카페·학교·회사 같은 공용 와이파이, 게스트 와이파이, 휴대폰 데이터·핫스팟에서는 막히거나 연결되지 않을 수
  있습니다. 특히 양쪽 다 휴대폰 데이터면 연결되지 않을 가능성이 큽니다. 방은 집 인터넷에서 여는 것이 좋습니다.
- Windows는 처음 방을 열거나 참여할 때 방화벽 창이 뜨면 **개인 네트워크와 공용 네트워크 모두** 허용해 주세요(집
  인터넷도 Windows가 공용 네트워크로 보는 경우가 많고, 그러면 그 창이 공용 네트워크에서 게임을 막는 규칙도 만듭니다).
  PC에서 연 방에 다른 네트워크의 손님이 못 들어오면, 방을 연 상태에서 멀티플레이 화면의 **Windows 방화벽 허용**을
  누르세요. 관리자 확인 창이 뜨고, 게임의 예전 규칙을 지운 뒤 모든 네트워크에서 허용하는 규칙 하나를 만듭니다.
- Android는 플레이하는 동안 게임을 화면에 띄워 두세요. 다른 앱으로 가거나 화면이 꺼지면 연결이 끊길 수 있습니다.
- 포트는 `settings.ini`의 `mp_port`로 바꿀 수 있습니다(기본 47070).
- 실제로 서로 다른 네트워크 사이에서는 아직 충분히 확인하지 못했습니다. 안 되면 멀티플레이 화면의 "인터넷 주소"
  줄과 함께 [이슈](https://github.com/cailet0422/afe-port/issues)로 알려 주세요.

| 채팅 (멀티플레이 중) | T |
| 바로 저장 | Ctrl+S |
| 일시정지 메뉴 | Esc |

메뉴는 마우스(클릭, 휠), 방향키와 Enter·Esc, 또는 게임패드(십자키, A, B)로 씁니다. 조작은 일시정지 메뉴 → **설정**
→ **조작**에서 칸을 누르고 바꿀 키나 버튼을 누르면 바뀌고, 게임패드 버튼도 여기서 정합니다. 한글 입력 화면에서는 실제 키보드로 두벌식 입력을 할 수 있습니다(한/영 키, 오른쪽 Alt 또는
Shift+Space로 전환). 입력 중에는 **Shift+Enter**(또는 Ctrl+Enter)가 Start처럼 글을 끝냅니다. Enter는
줄바꿈이고, 더 바꿀 줄이 없으면 다음 줄로, 편지에서는 맺음말로 넘어가며 맺음말에서는 끝내기입니다. Start를 Home처럼
글자를 치지 않는 키에 정해 두었다면 그 키로도 끝낼 수 있습니다.

### 터치 조작

일시정지 메뉴 → **설정** → **게임** → **터치 조작**(`settings.ini`의 `touch_controls`; Android 기본은 화면 게임패드):

- **화면 게임패드**: 게임 위에 게임큐브 패드를 그립니다. 그 아래 **패드 배치 편집...**에서 버튼·십자 버튼·스틱을 끌어서
  옮기고, 하나를 고른 뒤 크기를 바꿉니다(50~200%). **모두 원래대로**로 되돌립니다.
- **풀 터치**: 패드 없이 손가락으로 세상을 직접 눌러 합니다.
  - 땅을 **누르면** 그곳으로 걷고, **꾹 누르고 있으면** 누른 곳으로 달리고, **끌면** 끈 방향으로 달립니다.
  - **주민을 누르면** 다가가서 말을 겁니다. 대사가 떠 있을 때 누르면 넘어가고, 선택지는 눌러서 고릅니다.
  - **물건을 누르면** 다가가서 씁니다: 물건·꽃·잡초는 줍고, 나무는 흔들고(도끼면 베고), 표지판·우체통·가구는
    씁니다. 삽을 들었으면 땅을 눌러 그 자리를 파거나 구멍을 메우고, 잠자리채·낚싯대는 가까운 곳을 누르면 그쪽으로
    휘두르거나 던집니다. 자기 캐릭터를 누르면 A입니다.
  - **우편함, 게시판, 지도판·음악판, 표지판, 하니와, 주민 집 문**: 누르면(위쪽을 눌러도 됨) 그것이 반응하는 쪽(게시판은
    정면, 우편함은 우편함 앞)으로 가서 씁니다. 그 자리에서 반응이 없으면 다른 쪽으로 돌아가 다시 해 봅니다.
  - **이벤트**: A가 필요한 곳(함정에서 빠져나오기, 이벤트 장면, 배)은 아무 곳이나 누르면 됩니다. 눈덩이는 함께 걸어서
    굴리고, 아침 체조는 스틱처럼 끌기를 따라 합니다.
  - 위쪽 아이콘: 왼쪽 위에 일시정지 메뉴·저장·게임패드, 오른쪽 위에 지도·소지품. 소지품에서는 칸을 누르면 명령이
    뜨고(손에 든 것이 있으면 그 칸에 놓음), 명령을 눌러 고르며, **물건을 끌어서** 다른 칸이나 자기 캐릭터 위에
    놓으면 옮기거나 입고 듭니다. 지도에서는 구역을 누릅니다. X로 닫습니다.
  - **우편함**은 소지품처럼 씁니다: 편지를 누르면 명령이 뜨고, 우편함의 편지를 끌어서 내 편지 칸에 놓습니다. 편지가
    가득 차서 묻는 창에서는 왼쪽 절반이 "좋아", 오른쪽 절반이 "안돼"입니다. **게시판**: 밀어서(또는 쪽의 왼쪽·오른쪽
    절반을 눌러) 쪽을 넘기고, 위아래로 밀거나 아래 버튼을 눌러 최신 글·첫 글로 가며, 버튼을 눌러 글을 쓰거나
    그만둡니다. **읽고 있는 편지**는 누르면 닫힙니다.
  - **도구**: 가운데 칸에 손에 든 도구와 소지품 속 앞뒤 도구가 보입니다. 좌우로 **밀거나**(또는 옆을 눌러) 바로
    바꿔 듭니다.
  - **가구 배치 모드**(자기 집 안에서 의자 아이콘): 가구를 눌러 고르고, 끌어서 옮기고(놓을 수 있으면 초록), 화살표로
    돌리고, 가방 아이콘으로 소지품에 넣고, 아래쪽 소지품의 가구를 바닥으로 끌어다 놓습니다. 방의 가구나 아래 줄의 가구를
    누르면 그 이름이 나옵니다. 체크 표시로 끝냅니다.
  - 타이틀 화면에서는 아무 곳이나 누르면 시작합니다(START).
  - 그 밖에 버튼이 필요한 곳(다른 메뉴, 패미컴 게임)에서는 게임큐브 패드가 저절로 뜨고, 게임패드 아이콘으로 언제든 띄울
    수 있습니다.

## 알려진 제한

- SD 카드, GBA 연동, 카드e리더는 "장치 없음"으로 처리됩니다(게임이 각자의 안내 문구를 보여 줍니다).
- 한글로 길게 쓴 편지에는 주민이 답장하지 않습니다. 한글패치가 답장 여부를 일본어 낱말 표로 정하는
  코드를 그대로 두었기 때문이며, 게임큐브에서도 같습니다.
- 일본어판에서 만든 세이브를 한글패치 디스크로 불러오면 세이브에 저장된 이름이 한글 글자와 섞여
  보입니다(게임큐브에서도 같습니다).

## 소스에서 빌드하기

빌드에도 본인 디스크가 필요합니다. 디컴프의 매칭 빌드와 일부 생성 소스를 디스크에서 만들기 때문입니다.
Linux(데스크톱 기본값인 32비트)에서 빠르게 시작하려면:

```sh
sudo apt install gcc-multilib g++-multilib cmake ninja-build python3 libsdl2-dev:i386 libgl-dev:i386
git clone --recursive https://github.com/cailet0422/afe-port.git
cd afe-port
python3 pc/tools/gcdisc.py extract-orig <디스크.ciso> decomp/orig/GAEJ01_01
(cd decomp && python3 configure.py --version GAEJ01_01 && ninja)
cmake -S pc -B pc/build32 -G Ninja -DCMAKE_TOOLCHAIN_FILE=$PWD/pc/cmake/Toolchain-multilib32.cmake
ninja -C pc/build32
```

디스크 이미지를 `pc/build32/bin/rom/`에 넣고 `pc/build32/bin/DobutsuNoMoriEPlus`를 실행합니다. 디컴프를
다른 곳에 두었다면 cmake에 `-DDECOMP_ROOT=<afe-decomp 경로>`를 줍니다.

그 밖의 빌드 — MinGW 교차 빌드로 Windows, 64비트(`-DPC_ALLOW_64BIT=ON`), Android(Gradle), 배포용 에셋
없는 빌드(`-DPC_STRIP_ASSETS=ON`과 `dist` 타깃) — 는 아래 개발 문서에 있습니다.

## 기여하기

게임 코드의 PC용 수정은 afe-decomp에 `#ifdef TARGET_PC` 안으로만 커밋합니다. 그래야 매칭 빌드가 원래
바이너리를 그대로 만듭니다(해시는 [docs/README.ko.md](docs/README.ko.md)에 있습니다). 그 커밋이 들어가면 이
저장소에서 `decomp` 서브모듈을 올립니다.

게임 데이터(디스크 이미지, 디스크에서 추출한 에셋, 그것이 들어간 빌드 결과물 — 에셋을 넣어 빌드한 실행
파일·APK)는 절대 커밋하지 않습니다.
